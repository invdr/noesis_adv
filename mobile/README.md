# Мобильное приложение (в будущем)

Мобильное приложение Noesis планируется на **Expo (React Native)** и будет
жить в отдельной ветке `mobile`, чтобы не тянуть нативные зависимости в основной
монорепо. Приложение переиспользует контракты из `packages/contracts` и тот же
API бэкенда.

Пока это только указатель — реализация появится позже.
