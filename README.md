# Noesis

Монорепо CRM и публичного сайта рекламного агентства **Noesis** — продажа
рекламы на сити-форматах в городе Грозный.

Проект собран на основе кода [tower-site](https://github.com/invdr/tower-site):
переиспользуется всё домен-независимое ядро CRM, удалено неприменимое
(калькулятор рассрочки, планировки квартир), выполнен ребрендинг и перекраска.
Доменная специфика наружной рекламы вынесена в каталог конструкций, бронирование
по периодам и карту города — см. [PRD.md](PRD.md) и [TASKS.md](TASKS.md).

## Состав

| Папка | Назначение |
| --- | --- |
| `website/` | Публичный сайт на Astro (SSG) |
| `webapp/` | CRM на React + Vite |
| `backend/` | API на Hono + Prisma + PostgreSQL 18 |
| `packages/contracts/` | Общие Zod-схемы, DTO и бизнес-хелперы |
| `infra/` | Docker Compose, nginx, деплой и фоновые скрипты VPS |
| `mobile/` | Заготовка под будущее мобильное приложение |

## Что уже работает (унаследовано и переиспользовано)

- **CRM**: заявки с ручным приёмом, воронки и этапы, контакты и партнёры,
  журналы событий, задачи «следующий контакт» и «Мой день», аналитика,
  справочники источников/типов контактов.
- **Приём заявок с сайта**: анти-спам, троттлинг, согласие на обработку ПДн
  (152-ФЗ, время + IP).
- **Контент публичного сайта**: каталог, новости/акции, документы, настройки
  «обвязки» сайта, отдельная публикация из CRM (черновик → «Опубликовать»
  → фоновая пересборка статики → атомарное переключение релиза).
- **Хранение файлов**: изображения с производными WebP под `srcset`, документы.
- **Инфраструктура**: Docker + nginx, деплой на VPS, бэкапы, CI (typecheck+тесты).

## Что предстоит (доменная достройка наружной рекламы)

- Каталог **рекламных конструкций** (сити-форматов): адрес, гео-координаты,
  формат/габариты, сторона, подсветка, охват, цена за период.
- **Инвентарь и бронирование** конструкции по периодам (месяц/сезон): статусы
  брони, проверка пересечений, сетка занятости.
- **Карта города** с конструкциями: базовая публичная карта уже есть, дальше
  нужны фильтры занятости и карта в карточке CRM.

Подробности и приоритеты — в [TASKS.md](TASKS.md).

## Дизайн

Акцентный цвет — **тёмно-красный** (`#A4161A`), фон светлый. Синий из палитры
убран полностью. Растровый логотип-плейсхолдер заменяется при редизайне бренда.

## Быстрый старт

```bash
bun install
bun run db:up
bun run --cwd backend prisma:migrate
bun run --cwd backend db:seed
bun run dev
```

Проверки:

```bash
bun run typecheck
bun run test
bun run build
```

## Публикация сайта

Сайт статический: данные и настройки из CRM попадают в HTML на этапе сборки.
Сохранение контента в CRM только помечает правки как неопубликованные. Чтобы
обновить публичный сайт, админ нажимает «Опубликовать сайт», после чего
фоновый сборщик на VPS пересобирает сайт и атомарно переключает релиз.

## Прод

Прод разворачивается на VPS вручную по SSH (автодеплоя нет). Домен, сервер и
секреты задаются при провижининге — см. [docs/DEPLOYMENT_VPS.md](docs/DEPLOYMENT_VPS.md).

```bash
export PATH="$HOME/.bun/bin:$PATH"
cd /root/noesis_adv
git pull origin main
bun run deploy:vps
```

Если VPS уже занят другим nginx/PostgreSQL-приложением и Noesis нужно подселить
рядом, используйте no-Docker дорожку:

```bash
cp infra/no-docker.env.example infra/no-docker.env
# заполнить секреты и домен
bash infra/deploy-no-docker.sh   # первый запуск сам установит bun при необходимости
# дальше можно: bun run deploy:vps:no-docker
```
